# A Hair’s Breadth from Death

Text-based game "A Hair’s Breadth from Death" (Russian: "На волосок от смерти") by Evgeniy Tugolukov (Russian: Евгений Туголуков), a.k.a. Korwin, and Jenny (Russian: Дженни).

The game is in Russian, developed for FireURQ, and adapted for [UrqW](https://github.com/urqw/UrqW) text-based game engine.

This repository contains the source code and other resources of the game. The game is available for launch in the [UrqW engine online catalog](https://urqw.github.io/UrqW/?id=hair_s_breadth_from_death).

The game was first published on August 7, 2012.

Interactive fiction identifier (IFID) of the game which is its MD5 hash: C7B9E28C17A3588BD512D1E0403E2E2F

## Description

- Теперь твоё задание, Виктор, - командор Биг повернулся к тебе. - Двигаться от базы на север на расстояние до 500 километров, высота 5000 метров. Задача - поиск искусственных объектов. Обнаружишь что-то интересное - спустишься пониже. Ниже 300 метров старайся не спускаться. Высадку тоже запрещаю. По достижении заданного удаления - возвращаешься зигзагом шириной до 50 километров, радиус разворота 5 километров. В твоём распоряжении 6 часов. Вопросы есть?
